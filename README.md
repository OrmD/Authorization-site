# Проєкт: Система авторизації користувачів

## Опис проєкту

Цей проєкт — це веб-додаток з авторизацією користувачів, реалізованою через **LocalStorage**. Система дозволяє реєструватися, входити в обліковий запис, а також відображати дані користувача на сторінці. Реєстраційні дані зберігаються в **LocalStorage**, а валідація перевіряє унікальність користувачів.

## Використані технології

### Основні технології:

- **HTML, CSS, JavaScript**
- **SCSS** (змінні, міксіни, вкладеність, умови)

### CSS-функціонал:

- **Flexbox**, **анімовані ефекти**
- **Медіа-запити** для адаптивності
- **Keyframes** для створення анімацій

### JavaScript-функціонал:

- **Модульність JS** для кращої структури коду
- **Робота з класами блоків** для організації елементів
- **LocalStorage**:
  - Збереження реєстраційних даних
  - Перевірка унікальності користувача
  - Відображення інформації на сторінці
- **setTimeout** для асинхронних операцій
- **Робота з URL (`window.location.hostname`)** для обробки навігації

### Сторонні бібліотеки:

- **Swiper.js** — для створення інтерактивного слайдера

## Функціонал

- **Адаптивний дизайн**, що коректно відображається на різних пристроях
- **Інтерактивні елементи**:
  - Спливаючі вікна
  - Слайдер
  - Ховер-ефекти з анімаціями
- **Авторизація користувача через LocalStorage**:
  - Реєстрація нового користувача
  - Перевірка унікальності користувачів
  - Вхід у систему
  - Відображення користувацьких даних
  - Обробка помилок при повторній реєстрації

## Запуск проєкту

1. Клонувати репозиторій:
   ```sh
   git clone https://github.com/your-repository.git
   ```
2. Перейти в папку з проєктом:
   ```sh
   cd auth-project
   ```
3. Запустити локальний сервер (наприклад, через Live Server або будь-який інший інструмент).

## Висновок

Цей проєкт демонструє просту та ефективну систему авторизації на основі **LocalStorage**, використовуючи **адаптивну верстку, кастомну валідацію та інтерактивні елементи** для покращеного UX.
